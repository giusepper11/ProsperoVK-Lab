# Contributing

Read AGENTS.md, the architecture and the active milestone. Open a focused issue or OpenSpec proposal before nontrivial implementation. Use a branch and reviewable pull request for subsequent work.

A PR must state the problem, milestone, approach, test commands and results, Linux/PS5 verification status, known limitations and upstream provenance. Include a minimal reproduction for driver issues. For performance changes attach comparable raw reports and correctness evidence.

Avoid unrelated formatting churn and vendor drops. Do not submit leaked material, console keys, private logs or game assets. Original-code license is pending maintainer approval; resolve it before accepting external code contributions or importing dependencies.
